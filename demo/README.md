# Демонстрационный дневник

`дневник.json` это выдуманные записи для проверки характера Лу. Настоящих записей здесь нет и быть не должно: дневник человека личный и в репозиторий не попадает.

Файл нужен, чтобы прогонять тестовые сценарии из `agent/lu/PERSONA.md` без поднятого продукта и видеть, срывается ли Лу в советы.

Запуск с ним:

```bash
LU_DIARY_FILE=demo/дневник.json python3 tools/run_session.py lu
```
